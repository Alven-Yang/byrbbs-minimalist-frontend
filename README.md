# 北邮人论坛 · 简约版

Tampermonkey 用户脚本，为北邮人论坛的**首页、分区目录、版面帖子列表和帖子详情页**提供简约布局。当前版本 **0.8.2**。默认开启，左下角「简约版」或 `Alt+M` 可切回原版。

本项目源自 [Hermi-Mire 的北邮人论坛简约版](https://github.com/Hermi-Mire/byrbbs-minimalist-frontend)。

## 特色功能

- **论坛首页**：模块卡片、热门话题序号、更舒适的字体与间距；保留原有模块、折叠和标签切换，近期热门话题所在栏目优先显示。
- **分区目录**：版面以卡片排列，保留版主、最新主题、在线人数和帖子统计，支持二级目录。
- **帖子列表**：突出帖子标题，置顶帖单独标记；保留状态、附件标记、作者、回复数及最后回复入口，兼容主题、原作、经典、保留、文摘模式。
- **分区导航**：首页与列表页顶部提供十个分区的快捷入口，窄屏可横向滚动。
- **切页不闪回经典界面**：等待内容时保持简约外壳与当前主题，新内容完成布局后再显示；加载异常时最多等待 3 秒便恢复可见，也可随时按 `Alt+M` 切回经典版。
- **返回保持滚动位置**：浏览器后退 / 前进时按历史记录恢复对应页面的位置，支持触控板两指横向返回；等待异步内容和图片布局完成后再恢复。帖子列表页主动刷新时回到顶部。
- **自动无缝翻页**：版面列表和帖子详情接近底部时自动追加下一页，标出页码并去重置顶帖；左下角按钮可暂停 / 恢复，失败时点击重试，末页自动停止。保留手动分页，并在本标签页内缓存最近 6 条浏览记录的追加内容，返回时恢复内容和位置。
- **分区侧栏常驻**：桌面端左侧固定显示各分区导航，滚动正文时仍可直接切换；窄屏保留抽屉菜单，避免遮挡内容。
- **自适应布局**：正文、帖子列表、操作栏与快捷回复共用内容列；首页和目录自动分栏，列表按正文可用宽度切换排版，分页与按钮自动换行。侧栏统一字号，长名称可换行且可滚动到底；底部浮层按实际高度避让。
- **修正原版问题**：网页缩放后精彩回复不再被裁切。
- **浮动标题 / 路径栏**：顶部向下滚动显示主题，向上滚动显示路径，点击主题回顶。
- **紧凑的帖子布局**：收紧楼层间距，完善 Markdown 表格样式，来源和修改记录收进折叠区域。
- **多图画廊**：每个多图楼层只显示一张大图，下方可横向滚动浏览所有缩略图，右上角显示进度。点缩略图、左右按钮或用方向键切换，点大图可打开灯箱放大。
- **媒体卡片**：点卡片才会加载外部播放器。
- **回到本楼顶部**：长楼层的楼顶滚出视野后，右下角会出现回到本楼顶部的按钮。
- **底部快捷回复**：固定在窗口底部。桌面端滚到页末时，帖子工具栏移回最后一楼之后。
- **深色模式**：覆盖上述页面，可手动切换或跟随系统；`Shift+点击` 主题按钮恢复跟随系统。
- **控制条与版面菜单**：取消左侧菜单，左下角切换经典布局，`☰` 打开完整版面菜单。
- **头像即资料入口**：取消`查看`按钮，点击头像可打开用户资料框。


### 其他

- 正文元信息（发信人 / 标题 / 发信站）及 `※ 来源`、`※ 修改` 淡化。
- 分页靠左、发文按钮靠右；楼层徽标移到用户名旁。
- 保留原站节点与链接，继续使用站点的搜索、关注、分页、分享、回复、收藏、精彩回复、只看此 ID、返回顶部等功能。
- 首页、目录、列表和详情页分别启用各自的样式；公共外壳持续保持，正文等待 AJAX 内容与当前路由一致后再显示，避免跳转时错套样式。详情页还会等待楼层出现，二级目录则核对最末级路径。

## 安装

**一键安装**：[点此安装](https://raw.githubusercontent.com/Alven-Yang/byrbbs-minimalist-frontend/refs/heads/codex/forum-layout/byrbbs-minimalist-frontend.user.js)（Tampermonkey 会弹出安装页）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击 [`byrbbs-minimalist-frontend.user.js`](byrbbs-minimalist-frontend.user.js) 文件，选择 “Raw” 查看原始内容
3. Tampermonkey 会自动弹出安装提示，点击“安装”即可

或者手动安装：打开 Tampermonkey 控制面板 → 新建脚本 → 粘贴 `byrbbs-minimalist-frontend.user.js` 的全部内容 → 保存。

安装后打开论坛首页、分区目录、版面帖子列表或帖子详情页，左下角出现「简约版」按钮即生效。已有用户更新脚本后刷新论坛页面即可。

## 注意事项

- 作用于首页（`#!default` 或根路径）、分区目录（`#!section/...`）、版面帖子列表（`#!board/...`）和详情页（`#!article/...`），也支持对应的直接访问路径。其他页面保持原站布局。
- 依赖站点现有 DOM 和 CSS，站点改版后可能失效；布局异常时按 `Alt+M` 切回经典版。
- 0.6.0 根据登录后的首页、十个分区目录和多个版面的实际 DOM 适配，并使用原站 CSS 与示例数据进行本地浏览器验证；0.6.2 增加返回位置恢复，0.7.0 增加自动无缝翻页，0.7.1 增加常驻分区侧栏，0.7.2 修正侧栏与底部控制条的遮挡，0.7.3 修正常驻侧栏后的正文居中，0.7.4 加强返回位置恢复，0.7.5 修正论坛回顶覆盖离开前位置的问题，0.7.6 支持快速进入后立即返回，0.7.7 增加历史状态丢失时按路由恢复位置，0.7.9 修复触控板两指横向返回手势误取消滚动位置恢复的问题，0.7.10 区分帖子列表刷新回顶与后退恢复位置；更新脚本后刷新论坛页面即可。
- 与其他修改版面的用户脚本可能冲突，可暂时停用其中一个。
- 自动翻页默认开启，开关会记住；若同时使用其他翻页脚本，请在本论坛只开启其中一个。追加内容的缓存只保存在当前标签页内存中，刷新或关闭后释放。
- 自动翻页通过同源请求获取下一页。主动点击赞、踩或收藏时，脚本调用论坛接口提交相应操作。外站播放器只在点击媒体卡片后加载。界面偏好保存在 `localStorage` 的 `bym-enabled`、`bym-theme` 和 `bym-auto-pager` 中。

## 本地验证

运行 `node tests/auto-pager/server.mjs`，在浏览器打开输出的地址，页面会自动执行列表 / 楼层追加、暂停恢复、GBK 解码、失败重试、筛选保留及返回位置的回归检查。测试使用示例数据，不请求真实论坛。

运行 `node preview/server.mjs`，打开 `http://127.0.0.1:4318/` 可浏览首页、分区、列表与详情的示例页面，并展开侧栏子目录。0.7.11 已用论坛原始 CSS 检查 320、560、768、900、1099、1100、1280、1920 像素宽度，以及短窗口侧栏滚动、多行快捷回复避让；自动翻页与返回位置的 25 项回归检查通过。
